# ✦ StudyMate AI

**Study smarter, not harder.**

StudyMate AI is a simple AI-powered study assistant that helps students convert their notes into summaries, quizzes, and flashcards.

## 🚀 Features

- Generate summaries from study notes.
- Create multiple-choice quiz questions.
- Generate flashcards for quick revision.
- Choose different answer styles.
- Dark mode support.
- Copy and download study material.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Gemini API
- Node.js
- Vercel

## ⚙️ How It Works

1. Enter your study notes.
2. Select your preferred answer style.
3. Click the Generate button.
4. Get your summary, quiz, and flashcards.

## 🔐 API Security

The Gemini API key is stored as an environment variable on the server. It is not exposed in frontend JavaScript or uploaded to GitHub.

## 🌐 Deployment

The project is deployed using Vercel.
